# Rights, display, and cache

`PUBLIC_DISPLAY`: `UNKNOWN`. This is the open condition. Ordinary-user display cannot be ready while the operation is unreviewed.

`LOCAL_CACHE`: `UNKNOWN`. First production does not durable-cache provider responses. Ephemeral in-memory handling of one request is the only processing form. A 504 is not repaired by a silent cache.

`REDISTRIBUTE`: `UNKNOWN` and ungranted. No raw proxy, bulk layer, or public mirror.

`OFFLINE_PACKAGE` and `PUBLIC_API`: ungranted.

License basis remains the 2026-09-23 review: USGS-authored material on a public-domain basis, embedded copyright caveat, attribution required. That review granted `AUTOMATED_QUERY` with constraints. It did not grant `PUBLIC_DISPLAY`.
