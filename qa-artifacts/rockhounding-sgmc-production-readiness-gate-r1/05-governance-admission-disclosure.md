# Governance, admission, and disclosure

Governance and operation authorization run before every transport call. Suspension blocks the call and keeps historical records.

Admission policy `policy-usgs-sgmc-geological-context` is geology and geological context only. The campaign rejected the same candidates for collection permission, site access, route access, closure, mining claim, land ownership, and land management.

Disclosure runs before materialization. `UNKNOWN` sensitivity is withheld. `PUBLIC_MAP` in the disclosure policy does not authorize the `PUBLIC_DISPLAY` operation.
