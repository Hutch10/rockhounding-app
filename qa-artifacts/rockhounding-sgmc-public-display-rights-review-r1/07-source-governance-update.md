# Source governance update

`sgmcAuthorizationRequest` still grants only `AUTOMATED_QUERY`.

`sgmcPublicDisplayAuthorizationRequest` grants only `PUBLIC_DISPLAY` for `res-usgs-sgmc-geology`, with attribution required. A mismatched resource, a superseded review state, or an unknown review state does not authorize it.

The governance record's allowed use remains `GEOLOGICAL_CONTEXT`. The governance schema version stays 1.0.0.
