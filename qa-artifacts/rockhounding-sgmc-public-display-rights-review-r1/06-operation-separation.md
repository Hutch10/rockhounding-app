# Operation separation

`PUBLIC_DISPLAY` is an explicit grant on `res-usgs-sgmc-geology`.

`AUTOMATED_QUERY` remains a different grant. Requesting display with only the query grant is `OPERATION_NOT_GRANTED`.

`REDISTRIBUTE`, `PUBLIC_API`, `LOCAL_CACHE`, `OFFLINE_PACKAGE`, `MODEL_INPUT`, `AI_PROCESSING`, and `TRAINING_USE` stay ungranted. Redistribution and caching remain `UNKNOWN` on the license profile.

Display does not admit evidence, disclose geometry, or authorize collection.
