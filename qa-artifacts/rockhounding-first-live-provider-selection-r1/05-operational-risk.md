# Operational risk

Retrieval date: 2026-09-23.

SGMC has a documented page size of 2000 and no published requests-per-minute number. A later adapter must stop a partial page as partial coverage. An outage stays `FETCH_FAILED`. The geologic map does not decide safety, claims, or collection.

NWS rate limits are unpublished. The alerts page recommends requests no more often than about every 30 seconds. Over-limit responses are errors, not empty alert sets. The geolocation guide shows that the wrong zone filter drops warnings. An outage must not become "no hazard."

FIRMS resets a 5000-transaction window every 10 minutes. Large day ranges can count as several transactions. A quota error is not "no fire."

MLRS pages at 2000. A truncated claim page is not a complete claim set. Missing geometries are an upstream coverage gap.

Every candidate can be disabled by not calling it. No candidate is a system of record for Rockhounding decisions. Historical receipts stay pinned to whatever snapshot already exists. None exist for these providers yet.

Fixture requirement: each candidate can be represented by a saved official sample. This phase did not save one, because saving features would be a data retrieval. The next phase does that for the selected source only, from a minimized captured response, with the network still closed during adapter tests.
