# Disclosure and security

Retrieval date: 2026-09-23.

SGMC geometry is a published geologic map polygon. Expected classification is `PUBLIC`. Expected mode is `EXACT` for that already generalized map unit. Disclosure Governance still has to run before any public, export, or shadow surface. The polygon is not a private collecting site. User locations must not be joined into this source.

USMIN and any exact mine or prospect point are a higher disclosure class. They are easier to mistake for a place to go. They were not selected.

MLRS claim polygons are public land records. They are not specimen localities, and they are not the first geometry this platform should publish.

NWS alert polygons and zones are public safety messages. Publishing them is not a sensitive-locality problem. Misstating their meaning is the larger risk.

FIRMS detections are public satellite pixels. A free key is still a secret that must stay out of source, fixtures, logs, and provenance.

No candidate requires a write or admin credential. FIRMS is the only one that requires a read key. NWS requires a User-Agent string, which is an application identity, not a secret. The USGS and BLM services described here did not show a required key.
