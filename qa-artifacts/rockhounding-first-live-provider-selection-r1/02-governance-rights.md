# Governance and rights

Retrieval date: 2026-09-23.

USGS copyright page: USGS-authored data and information are in the U.S. public domain. Credit is requested. The USGS identifier is trademarked and is not granted. Some embedded non-USGS illustrations remain copyrighted.

SGMC service text: the product is, for the most part, in the public domain; copyrighted items noted in the text need the owner's permission; USGS liability is disclaimed; users should not imply USGS endorsement.

That is enough to draft a reviewed profile whose only granted operation is `AUTOMATED_QUERY`, with attribution required. Redistribution, public API, bulk download, model input, and training use stay ungranted. Embedded third-party copyright, if a field is marked copyrighted, is quarantined rather than copied forward.

NWS API page: open data, free for any purpose, no fee. A later public display of an alert is still a separate disclosure and redistribution decision in this platform. The NWS permission does not by itself become a Rockhounding `PUBLIC_API` grant.

FIRMS: open sharing with a requested citation and disclaimer. The `MAP_KEY` is an access control, not a license to skip attribution.

USMIN: USGS public-domain policy applies to USGS-authored content. The database's developing scope is a coverage limit, not a broader license.

MLRS: federal map service with no key on the description page. A public claim polygon is not permission to collect and is not proof that unmapped ground is unclaimed.

None of these terms were treated as collection permission or as evidence admission.
